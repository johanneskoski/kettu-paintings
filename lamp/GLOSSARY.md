# Glossary (draft): lamp

`opas` = guide (folder of guide images)
`maalaus` = painting
`turva` = safety (short for the safety essay)
`lahde` = source (the photo)
`ulos` = out (output folder or file)
`siemen` = random seed
`alue` = region (0 background, 1 floor, 2 chest of drawers, 3 lamp, 4 light, 5 paper)
`vari` = color
`valo` = light
`kulma` = angle (stroke direction)
`tark`, `tarkeys` = importance, precision
`muste` = ink (form text and signature)
`tiedot` = data, info (the JSON with traced shapes)
`paperi` = paper; corners `vy`, `oy`, `oa`, `va` = top left, top right, bottom right, bottom left
`lomake` = form (the sheet with the declaration)
`allekirjoitus`, `kirjain` = signature, letter
`taitos` = fold
`lattia`, `laudat` = floor, floorboards
`pakopiste` (`PAKO_X`, `PAKO_Y`) = vanishing point
`lipasto`, `kaappi` = chest of drawers
`varjostin` = lamp shade
`hylsy` = socket cap on top of the shade
`aukko` = opening of the shade
`nivel`, `pallo` = joint, ball (ball joint)
`kaula` = neck (the flexible tube)
`kahva` = handle
`jalka`, `kupu` = base of the lamp, dome
`katkaisin` = switch
`johto` = cord
`liitu`, `LIIDUT`, `nyppy`, `kerros`, `kyna` = pastel stick, sticks, paper tooth, layer, pencil
