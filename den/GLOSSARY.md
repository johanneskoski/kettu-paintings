# Glossary draft: fox's den

Finnish identifiers in `opas_pesa.py`, `pesa.html` and `aja_piirros.cjs`.

- `opas` = guide (the guide images and their folder)
- `ulos` = out (output folder or file)
- `vari` = color
- `alue` = region (0 sky, 1 snow, 2 earth, 3 wood and roots, 4 warm light, 5 small objects)
- `valo` = light
- `kulma` = angle (stroke direction)
- `tark` / `tarkeys` = level of detail / importance
- `tiedot` = data (the JSON file with tracks, edge lines and positions)
- `reunat` = edges (edge lines)
- `maski` / `aseta` / `sekoita` = mask / set (color, region, angle, detail, light) / mix
- `kohina` = noise
- `siemen` = seed (random seed)
- `lumi` / `maa` = snow / earth
- `runko` / `kaarna` = trunk / bark
- `OKSAT` / `JUURET` / `SORMET` = branches / roots / root fingers
- `KUUSET` / `LEHDET` / `KIVET` = spruces / leaves / stones
- `PESA` / `SUU` = den / mouth of the den
- `KAYTAVA` = tunnel
- `OVI` / `kahva` = door / handle
- `LYHTY` = lantern
- `KIRJE` / `PAPERIT` / `KARTTA` = letter / papers / map
- `KETTU` / `HANTA` = fox / tail
- `LUMIKKO` = least weasel
- `janis` = hare
- `JALJET` / `laji` / `suunta` = tracks / species / direction
- `LIIDUT` / `liitu` = pastel sticks / pick a pastel stick
- `NYPPY` = tooth (grain of the paper)
- `kerros` / `painaKerros` = layer / press a layer onto the paper
- `nayte` / `viiva` / `pastelli` / `kyna` = sample / streamline / pastel stroke / pencil stroke
- `tila` / `valmis` / `virhe` = status (also blend mode) / done / error
