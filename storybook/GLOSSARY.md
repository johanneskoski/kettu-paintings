# Glossary (draft)

Most identifiers in this folder are already in English. The Finnish ones are the file (module) names and a few names and words.

## Identifiers
- `akvarelli` = watercolor (the painting machine module)
- `hahmot` = characters (the module with the fox and weasel shapes; also the default output name `hahmot.jpg`)
- `hahmot_testi` = characters test (paints the characters; runs alone as a quick test)
- `pesa_satu` = den fairy tale (the full storybook picture; `pesä` = den or nest, `satu` = fairy tale)
- `lumi` (in `LUMI_OUTLINE`, `LUMI_EAR`, `LUMI_EYE`, `LUMI_NOSE`, `LUMI_PAWS`, mask keys `lumi`, `lumi_full`, `lumi_paws`, pencil key `lumi_fur`) = Lumi, the name of the weasel in the picture; the word also means snow

## Names used in the comments
- Kettu = "fox"; the fox in the picture
- Lumi = "snow"; the weasel in the picture
- Näkyvä muisti = "Visible Memory"; the title of the picture

## Terms chosen in the translation
- lasuuri = glaze (a transparent layer of watercolor)
- pesu = wash
- ulottuvuuskenttä = reach field (how far a wash reaches, in pixels)
- kukkiminen = bloom (slow variation inside a large wash)
- viivoitus = hatching
- värikynä = colored pencil
- kehtojuuri = cradle root (a root that holds the den from below)
- jatke = stub (the short piece that carries a root through the snow layer)
- käytävä = tunnel (the passage from the den to the surface)
