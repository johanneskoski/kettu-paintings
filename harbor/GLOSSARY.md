# Glossary draft: harbor

Finnish identifiers in `opas_kuvasta.py`, `maalaus.html` and `aja_piirros.cjs`.

- `opas` = guide (the guide images and their folder)
- `ulos` = out (output folder or file)
- `kuva` = image
- `vari` = color
- `alue` = region (0 sky, 1 water, 2 land and trees, 3 covers and boats, 4 light, 5 buoys)
- `valo` = light
- `kulma` = angle (stroke direction)
- `tark` / `tarkeys` = level of detail / importance
- `muoto` = form (form light; flat and unused here)
- `tiedot` = data (the JSON file with edge lines)
- `reunat` = edges (edge lines)
- `ranta` = shore (shoreline)
- `vesi` = water
- `taivas` = sky
- `peite` = cover (boat tarpaulin)
- `vene` = boat
- `POIJUT` = buoys
- `TANGOT` = poles (of the buoys)
- `KOYDET` = ropes
- `LAMPPU` = lamp
- `heijastus` = reflection
- `kohina` = noise
- `siemen` = seed (random seed)
- `LIIDUT` / `liitu` = pastel sticks / pick a pastel stick
- `NYPPY` = tooth (grain of the paper)
- `kerros` / `painaKerros` = layer / press a layer onto the paper
- `nayte` / `keskiNayte` = sample / averaged sample
- `viiva` = line (the streamline a stroke follows)
- `pastelli` / `kyna` = pastel stroke / pencil stroke
- `tila` / `valmis` / `virhe` = status / done / error
